# The Dog Reviews the Mailman

One funny one-line review a dog gives the mailman, written by
`main.py` (Python standard library only, fully deterministic) to
`/output/entry.txt`.

## The line

> He tried to bribe me with a biscuit. I ate it, then barked anyway.
> Five stars for the biscuit, one star for the mailman.

120 characters, one line. The joke is the dog's side of the visit:
the mailman tried a bribe, the dog took the biscuit and barked
anyway, then rated the biscuit five stars and the mailman one.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`. Running it twice produces
byte-identical output.
